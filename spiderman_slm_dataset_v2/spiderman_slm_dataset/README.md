# Spider-Man SLM Dataset v2

This dataset is an instruction-tuning starter dataset for a small language model.

It now includes a dedicated COMICS section covering:
- Spider-Man creators: Stan Lee and Steve Ditko
- First appearance: Amazing Fantasy #15
- Publication: August 1962
- The Amazing Spider-Man #1 and early comic history
- Early supporting characters and villains
- Major comic villains and allies
- Peter Parker relationships
- Miles Morales and Spider-Verse
- Alternate Spider characters
- Avengers / Fantastic Four connections
- Continuity and hallucination handling

Primary comic sources:
Marvel — Amazing Fantasy #15:
https://www.marvel.com/comics/issue/16926

Marvel — Spider-Man Origins:
https://www.marvel.com/comics/guides/1700/spider-mans-origins

Library of Congress — original Amazing Fantasy #15 artwork:
https://www.loc.gov/loc/lcib/0805/spiderman.html
